# Exercícios de Golang - Guia Completo

Este diretório contém **30 exercícios práticos** cobrindo todos os conceitos essenciais do Go para desenvolvimento real.

## 📚 Índice de Exercícios

### Etapa 1: Fundamentos Básicos (01-09)

1. **01-instalacao-e-ambiente.go** - Configuração inicial e primeiro programa
2. **02-variaveis-e-constantes.go** - Declaração de variáveis e constantes
3. **03-tipos-dados-primitivos-compostos.go** - Tipos de dados do Go
4. **04-operadores.go** - Operadores aritméticos, lógicos e de comparação
5. **05-controle-de-fluxo.go** - if/else, switch
6. **06-loops.go** - for, range
7. **07-funcoes.go** - Funções, múltiplos retornos, variádicos
8. **08-manipulacao-slices-maps-strings.go** - Manipulação de coleções
9. **09-escopo-e-ponteiros.go** - Escopo de variáveis e ponteiros

### Etapa 2: Intermediário (10-19)

10. **10-structs-e-embedding.go** - Estruturas de dados e composição
11. **11-metodos-e-receivers.go** - Métodos e receivers (value vs pointer)
12. **12-interfaces-e-type-assertions.go** - Interfaces e polimorfismo
13. **13-genericos.go** - Generics (Go 1.18+)
14. **14-tratamento-erros.go** - Error handling, panic, recover
15. **15-concorrencia-basica.go** - Goroutines e channels
16. **16-concorrencia-avancada.go** - Mutex, WaitGroup, Context
17. **17-biblioteca-padrao-http-json.go** - HTTP server e JSON
18. **18-testes-e-benchmarking.go** - Testes unitários e benchmarks
19. **19-packages-e-modules.go** - Organização de código

### Etapa 3: Avançado e Real-World (20-30)

20. **20-file-io.go** - Leitura e escrita de arquivos
21. **21-time-e-date.go** - Operações com datas e horas
22. **22-regex-e-string-avancado.go** - Expressões regulares e strings
23. **23-sorting-e-searching.go** - Ordenação e busca
24. **24-worker-pools.go** - Worker pools para concorrência
25. **25-select-avancado.go** - Multiplexação de channels
26. **26-custom-errors.go** - Erros customizados e wrapping
27. **27-encoding-base64-hex.go** - Encoding/decoding de dados
28. **28-command-line-args.go** - Argumentos e flags de CLI
29. **29-logging.go** - Sistema de logging
30. **30-reflection-basico.go** - Reflection (casos avançados)

## 🚀 Como Usar

### Executar um Exercício

```bash
# Executar exercício específico
go run 01-instalacao-e-ambiente.go

# Ou compilar primeiro
go build 01-instalacao-e-ambiente.go
./01-instalacao-e-ambiente
```
